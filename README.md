# Sistema de Gestión Comercial POO

## Descripción

Sistema de Gestión Comercial desarrollado en JavaScript utilizando Programación Orientada a Objetos (POO).

El sistema permite:

- Registrar clientes
- Registrar productos
- Registrar ventas
- Calcular subtotales
- Calcular IVA
- Generar facturas
- Generar reportes
- Registrar auditorías

## Tecnologías utilizadas

- JavaScript
- Node.js
- Git
- GitHub

## Funcionalidades

### Gestión de Clientes

Permite registrar clientes con:

- ID
- Nombre
- Apellido
- Email
- Teléfono

### Gestión de Productos

Permite administrar:

- Código de producto
- Nombre
- Categoría
- Precio
- Stock

### Gestión de Ventas

Permite:

- Registrar ventas
- Asociar clientes
- Asociar productos
- Calcular subtotales

### Facturación

Permite:

- Calcular IVA (21%)
- Calcular total
- Emitir factura

### Reportes

Permite:

- Obtener ventas totales
- Analizar operaciones comerciales
